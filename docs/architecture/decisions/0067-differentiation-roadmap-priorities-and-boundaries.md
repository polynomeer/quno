# ADR-0067: 차별화 로드맵의 우선순위와 경계 — Stack Fingerprint 먼저, AI는 구조화 보조만

- 날짜: 2026-10-19
- 상태: 일부 대체됨(ADR-0068로) — 결정 2(AI는 답변을 생성하지 않는다)와 결정 5(서버는 코드를 실행하지 않는다)는 [ADR-0068](0068-living-engine-runner-and-ai-first-responder.md)이 조건부로 바꿨다. 결정 1·3·4·6은 유효하다.

## 배경 (Context)

Stack Overflow, Quora, 네이버 지식iN, 아하와 비교한 결과([competitive-analysis.md](../../product/competitive-analysis.md)), Quno의 데이터 모델(리비전, 답변-판본 연결, Cluster, Ward)은 차별점이지만 다음 세 가지가 비어 있었다.

- 약속한 핵심 차별점인 "구조화된 기술 버전 메타데이터"가 실제로는 자유 텍스트 `environment`와 태그 slug 수동 매핑이다. 버전 영향 감지는 "콘텐츠가 릴리스보다 오래됨"이라는 휴리스틱이라 어느 버전에서 유효한 답인지 모르고, 그래서 자동 OUTDATED 전환도 못 한다([ADR-0033](0033-technology-version-scan-detection-only-no-auto-outdated.md)).
- 가장 큰 경쟁자가 AI 어시스턴트인데 AI 기능이 전혀 없다.
- 개발자의 작업 흐름(IDE·터미널·GitHub) 밖에 있다.

사용자가 제안된 7개 항목과 콜드 스타트 전략을 모두 계획에 넣기로 했다. 남은 결정은 순서와 경계다.

## 결정 (Decision)

1. **Stack Fingerprint + 적용 버전 범위(Phase 63)를 키스톤으로 가장 먼저 한다.** Migration Radar(69), 스택 자동 첨부 CLI(65)가 이 데이터에 기대고, 영향 감지의 정밀도 문제(위 첫 번째)를 직접 푼다. 대안이던 "AI 기능을 먼저"는 기각했다. 차별점이 비어 있는 상태에서 AI를 먼저 붙이면 Quno가 AI 채팅과 구별되지 않는다.
2. **AI는 구조화 보조로만 쓴다.** 로그에서 환경·에러 추출, 중복 후보 의미 검색, 클러스터 요약 초안이 범위이고, 답변은 생성하지 않으며 초안은 사람이 승인해야 게시된다. 제품 원칙 4를 로드맵 경계로 못박은 것이다. 사용자 데이터를 외부 모델에 보내는 정책(옵트인·마스킹·비용 상한)은 Phase 67 착수 시 별도 ADR로 정한다.
3. **AI 에이전트를 경쟁자가 아니라 유통 채널로 쓴다.** MCP 서버(Phase 65)는 읽기 전용부터 열고, 쓰기는 사용자 승인을 거친다.
4. **자동 판정은 늘리지 않는다.** 적용 범위가 정밀해져도 OUTDATED 전환은 ADR-0033대로 사람이 한다. 외부 이벤트(GitHub 이슈 종료, CI 통과)도 상태 전환을 "제안"할 뿐이다.
5. **서버는 사용자 코드를 임의 실행하지 않는다.** 답변 검증은 외부 CI 결과를 받는 방식으로만 한다. 자체 샌드박스는 보안 부담 대비 이득이 작다고 판단해 기각했다.
6. **콜드 스타트는 좁게 시작한다.** 한국어 백엔드 개발자(Kotlin/Spring/Redis/PostgreSQL)가 첫 대상이다. 범용 Q&A 확장은 하지 않는다.

## 결과 (Consequences)

- 63이 늦어지면 65·69도 함께 늦어진다. 반대로 64·68·70은 63과 독립이라 병행할 수 있다.
- 의존성 파일 파싱은 사설 패키지명 같은 민감 정보를 다룬다. 원본은 저장하지 않고 파싱 결과만 저장하며 저장 전 제외할 수 있게 하는 것을 63의 설계 전제로 한다.
- 개인 액세스 토큰(PAT)이 새 인증 수단이 되면 현재 IP 기준 인메모리 레이트리밋([production-readiness.md](../../product/production-readiness.md) B-2)으로는 토큰 단위 한도를 걸 수 없다. Phase 65에서 함께 다뤄야 한다.
- 여기서 정한 순서는 데이터가 쌓인 뒤 재검토한다. 특히 Migration Radar는 데이터가 임계치 미만이면 노출하지 않는다.
