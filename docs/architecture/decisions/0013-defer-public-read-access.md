# ADR-0013: 질문/프로필 조회의 비로그인 공개 여부는 보류하고 당분간 인증을 계속 요구

- 날짜: 2026-08-24 (Phase 2.2에서 최초 보류), 2026-08-24 재확인 (Phase 3.3)
- 상태: 승인됨 (보류 자체가 결정) — 재검토 예정

## 배경 (Context)

Question 생성/조회 API를 만들 때(Phase 2.2), `SecurityConfig`의 기본 규칙(`/api/v1/auth/**`만 공개, 나머지는 인증 필요)을 그대로 둘지, 질문 조회처럼 읽기 전용 API는 비로그인 사용자에게도 열지 결정해야 했다. Stack Overflow류 서비스는 검색엔진 유입을 위해 질문 조회를 공개하는 것이 일반적이지만, Quno는 아직 Search/Discovery 설계가 확정되지 않은 단계였다.

## 결정 (Decision)

**지금 결정하지 않는다.** `GET /questions/{id}`, `GET /users/{id}/profile`을 포함한 모든 조회 API는 다른 API와 동일하게 인증을 요구하는 `SecurityConfig` 기본값을 유지한다. Phase 3.3(사용자 프로필 라이트) 구현 시에도 이 보류를 재확인했다 — 새로운 근거가 없다면 매번 다시 논의하지 않고 "보류 중"이라는 상태를 그대로 유지한다.

## 결과 (Consequences)

- 비로그인 사용자는 질문/프로필을 볼 수 없다. 이는 검색엔진 유입, 소셜 공유 미리보기 등 마케팅 관점의 기능을 사실상 막고 있다는 것을 인지하고 있다.
- 이 결정을 미룬 채로 Search/Discovery(전용 검색엔진 도입, ADR-0008의 후속) 설계를 할 때 반드시 다시 꺼내야 한다 — 그때 "검색엔진 크롤링이 필요한가", "미리보기 카드가 필요한가"라는 구체적 요구가 생기면 판단 근거가 생긴다.
- 지금 임의로 공개/비공개를 정하지 않은 이유는, 그 시점의 실제 요구사항 없이 정하면 나중에 뒤집힐 가능성이 높다고 봤기 때문이다 — "결정하지 않기로 결정한다"는 것 자체도 ADR로 남길 가치가 있다고 판단해 기록한다.
