# ADR-0061: 디자인 시안 캔버스 기준의 프론트엔드 시각 체계 교체

- 날짜: 2026-10-09
- 상태: 승인됨

## 배경 (Context)

프론트엔드는 `docs/frontend/design.md` 7절의 semantic token 체계(`--surface`, `--brand`, `--success` 등)를 갖고 있었지만, 실제 값은 Tailwind 기본 팔레트에 가까웠다. 폰트는 Geist라서 한글 글리프가 없어 본문 대부분이 시스템 폰트로 떨어졌다. 그 결과 화면이 "살아있는 질문"(질문 상태·리비전·수락이 움직이는 모습)을 강조하지 못하는 범용 게시판처럼 보였다.

2026-10-09에 Claude Design 캔버스로 "Quno 디자인 시안"을 만들었다. 라이트/다크 각각 홈 피드, 질문 상세, 질문 작성, 모바일 질문 상세, 디자인 토큰 아트보드가 있다. 사용자가 이 시안대로 적용해 달라고 요청했다.

## 결정 (Decision)

- **토큰 값 교체, 이름 유지**: 기존 semantic token 이름은 그대로 두고 시안의 값으로 바꾼다. 다음 토큰을 추가한다.
  - `--canvas`(페이지 바탕)과 `--surface`(카드 면)를 분리한다. 회백색 바탕 위에 흰 카드를 올리는 구조다.
  - `--text-body`, `--border-strong`, `--brand-on-subtle`, `--success-strong`, `--success-border`, `--code-bg`, `--code-fg`, `--live`, `--live-ring`
- **색은 상태에만 쓴다**: StatusBadge 톤을 시안의 상태 표에 맞춘다.
  - OPEN: 테두리만
  - NEEDS_INFO: 적갈색
  - UPDATED: brand
  - RESOLVED: 초록 + 체크
  - OUTDATED: 중립 회색
  - OUTDATED는 기존 danger(빨강)에서 중립으로 바꿨다. "오래됨"은 경고가 아니라 맥락 정보이기 때문이다.
- **다크 모드**:
  - 바탕은 순수 검정이 아니라 푸른 기의 잉크 `#0e1014`로 하고, 면을 한 단씩 밝혀 깊이를 만든다.
  - 상태 색은 채도를 낮춘 어두운 배경 + 밝은 글자로 뒤집는다.
  - brand는 `#8ea2ff`로 밝히고, 그 위 글자는 어두운 색(`--brand-foreground`)으로 둔다.
- **폰트**:
  - 본문은 IBM Plex Sans KR(한글 지원)을 쓴다.
  - 숫자·태그·리비전 표기·코드는 JetBrains Mono를 쓴다.
  - 둘 다 `next/font/google`로 self-host한다.
- **Button danger 변형**: 단색 빨강 + 흰 글자 대신 subtle 배경 + danger 글자로 바꾼다. 기존 조합은 다크 모드에서 대비가 부족했다.
- **데이터는 지어내지 않는다**: 시안에는 다음 요소가 있지만, 현재 API 응답(`QuestionSummary` 등)에 해당 필드가 없어 이번 적용에서 뺐다.
  - 피드 카드의 답변 수·조회수·리비전 번호·최근 활동 줄
  - 질문 상세의 "질문의 생애" 타임라인
  - 홈 좌측 내비게이션
- **질문 작성 체크리스트**: 입력값에서 바로 계산한다(제목 15자 이상, 환경, 코드 블록, 로그, 태그). 서버 API가 필요 없고, design.md 11절대로 막는 오류가 아니라 제안으로만 보여준다.

## 결과 (Consequences)

- 전 화면이 같은 토큰을 공유하므로, 컴포넌트를 개별 수정하지 않은 페이지(태그, 프로필, 알림 등)도 색과 폰트는 자동으로 바뀐다. 다만 레이아웃까지 시안에 맞춘 화면은 다음뿐이다: 헤더, 홈, 질문 목록 카드, 질문 상세, 답변 카드, 질문 작성.
- 투표 버튼은 44px 원형이 되어 터치 타겟 기준을 만족한다. Watch/Save는 `aria-pressed` 토글로 상태가 보조기기에도 전달된다.
- 피드 카드의 답변 수·리비전·활동 신호와 질문 상세 타임라인은 [ADR-0062](0062-question-activity-signals-and-timeline.md)에서 백엔드 필드·API를 추가해 구현했다. 조회수는 여전히 보류다(집계 자체가 없다).
- 홈 좌측 내비게이션(`SideNav`)은 2026-10-09 후속 작업으로 구현했다. 범위는 다음과 같다.
  - 실제로 있는 라우트만 넣었다: 홈·질문·태그·조직, 내 활동의 Watching·저장됨·Direct Ask.
  - 시안의 "실시간 질문방"은 뺐다. 질문마다 붙는 기능이라 모아 볼 목록 페이지가 없다.
  - "Quno Flow"는 홈의 해당 섹션 앵커(`/#quno-flow`)로 연결한다.
  - Watching 옆 "N 변화"는 대시보드 `wardUpdates` 중 읽지 않은 수다.
  - design.md 8절의 반응형 기준대로 ≥1280px에서만 보이는 3열 레이아웃이다. 그 아래에서는 헤더 링크와 모바일 메뉴가 같은 라우트를 맡는다.
  - 3열을 담기 위해 본문 최대 폭을 헤더와 같은 1360px로 넓혔다.
- 사용자가 테마를 직접 고르는 토글은 없다. 지금처럼 `prefers-color-scheme`를 따른다.
