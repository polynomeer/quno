# 시드 코퍼스

`seed-chunk1~4.json`: 공개 GitHub 이슈에서 큐레이션한 해결 기록 105건. 모두 `verification: "unverified"`다. 큐레이션 절차와 한계는 [docs/product/phase-91-seed-curation.md](../../../docs/product/phase-91-seed-curation.md).

- 각 기록은 이슈의 사실을 영어로 요약하고 출처 링크를 붙인 것이다. `errorSample`만 이슈에서 그대로 인용했다(경로·사용자명 정제).
- 수정 버전은 이슈 본문·댓글·마일스톤에 근거한다. 추론이 들어간 부분은 `notes`에 적었다.
