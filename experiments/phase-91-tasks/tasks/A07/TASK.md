# 과제

MongoDB 비밀번호가 `my secret`(공백 포함)인 계정으로 접속하면 인증에 실패합니다. 같은 계정을 `mongosh`로 접속하면 문제가 없습니다. 서버 없이도 확인할 수 있도록, 설정한 계정 정보가 드라이버에 그대로 전달되는지를 검사하는 `MongoCredentialsTests`가 실패합니다. 원인을 찾아 고쳐 주세요.

- 성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(`./gradlew test` 통과).
- 제약:
  - Spring Boot 버전은 4.0.8로 고정되어 있습니다(조직 정책). 올리지 마세요.
  - 테스트 코드는 바꾸지 마세요.
  - 비밀번호는 여전히 `my secret`이어야 하며, 접속 대상 호스트·데이터베이스·인증 데이터베이스(`admin`)·사용자 이름은 바꾸지 마세요.
