# 과제

정산 서비스에 커버리지 리포트(JaCoCo)를 붙였더니 `./gradlew build`가 실패합니다. 테스트 자체는 통과하는 것으로 보이는데 빌드가 끝나지 않습니다. 원인을 찾아 고쳐 주세요.

- 성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(`./gradlew build` 통과).
- 제약:
  - Spring Boot 버전과 Kotlin 버전(2.2.21), 자바 툴체인(21)은 고정되어 있습니다. 바꾸지 마세요.
  - 테스트 코드는 바꾸지 마세요.
  - 커버리지 XML 리포트(`jacocoTestReport`)는 계속 생성되어야 합니다. JaCoCo를 제거하거나 리포트 태스크를 끄지 마세요.
