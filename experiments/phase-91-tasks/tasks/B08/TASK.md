# 과제

이 환경에서 아래와 같은 문제가 발생했습니다. 직접 재현할 수 없는 환경이므로, `evidence/`에 있는 환경 정보와 로그만으로 원인을 진단하고 해결 방법을 제시해 주세요.

**증상**: Apple Silicon Mac에서 `linux/amd64` 이미지를 만들도록 `imagePlatform`을 지정하면 `bootBuildImage`가 `Invalid buildpack reference`로 실패합니다. `imagePlatform` 없이(기본 설정으로) 빌드하면 성공합니다.

## 제출물

작업 디렉터리에 `DIAGNOSIS.md`를 작성합니다. 다음 세 절이 있어야 합니다.

- `## 원인` — 무엇 때문에 실패하는지 (근거가 되는 로그·환경 정보를 인용)
- `## 해결` — 이 환경에서 문제를 해결하는 구체적인 방법 (가능하면 대안도)
- `## 근거` — 위 진단에서 확신하는 부분과 추정인 부분을 구분

성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(형식 확인). 내용은 별도로 채점됩니다.
