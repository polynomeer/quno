# 과제

`CatalogApplicationTests`가 실패합니다. 같은 컴퓨터에서 개발용으로 앱을 띄워 둔 상태(관리 포트 18081 사용 중)에서 테스트를 실행하면 컨텍스트가 뜨지 않습니다. 테스트는 `RANDOM_PORT`로 실행하는데도 그렇습니다. 이전 메이저 버전에서는 앱을 켜 둔 채로도 테스트가 잘 돌았습니다. `./CHECK`는 이 상황을 재현하기 위해 테스트 동안 18081 포트를 점유합니다. 원인을 찾아 고쳐 주세요.

- 성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(`./gradlew test` 통과).
- 제약:
  - Spring Boot 버전은 4.0.1로 고정되어 있습니다(조직 정책). 올리지 마세요.
  - 테스트 코드(`*.kt`)와 `CHECK` 스크립트는 바꾸지 마세요.
  - `src/main/resources/application.yaml`의 운영 포트 설정(서버 8080, 관리 18081)은 그대로 유지되어야 합니다.
  - 관리 포트의 헬스 엔드포인트는 계속 제공되어야 합니다(비활성화 금지).
