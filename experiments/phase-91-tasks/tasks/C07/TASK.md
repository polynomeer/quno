# 과제

주문 결제를 처리하는 `CheckoutService`에 결제 수단(카드, 계좌이체)별 연동 클래스를 만들어 붙였더니, `CheckoutServiceTests`가 컨텍스트를 띄우는 단계에서 실패합니다. 원인을 찾아 고쳐 주세요.

- 성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(`./gradlew test` 통과).
- 제약:
  - Spring Boot 버전은 4.0.8로 고정되어 있습니다. 올리지 마세요.
  - 테스트 코드는 바꾸지 마세요.
  - 카드·계좌이체 연동 클래스는 둘 다 빈으로 남아 있어야 하고, `CheckoutService`의 기본 결제 수단은 카드여야 합니다.
