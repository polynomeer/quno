# 과제

환불 요청을 JDBC로 저장하는 작은 서비스를 만들었습니다. `RefundRepositoryTests`를 돌리면 애플리케이션 컨텍스트가 뜨지 못하고 테스트가 실패합니다. 원인을 찾아 고쳐 주세요.

- 성공 기준: `./CHECK`가 종료 코드 0으로 끝납니다(`./gradlew test` 통과).
- 제약:
  - Spring Boot 버전은 4.0.8로 고정되어 있습니다. 올리지 마세요.
  - 테스트 코드는 바꾸지 마세요.
  - 운영에서 쓰는 PostgreSQL 드라이버 의존성은 그대로 두세요. 이 환경에는 실행 중인 PostgreSQL이 없으므로 테스트는 외부 DB 없이 통과해야 합니다.
