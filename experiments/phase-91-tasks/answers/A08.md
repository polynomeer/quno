# A08 정답 (에이전트에게 공개하지 않는다)

- 출처: spring-boot#52207 (수정 PR, 수정 4.0.9)
- 보고일: 2026-10-14 (Boot 4.0.8에서 확인됨)
- 증상: `routes.properties`에서 `\#general=...`, `\#alerts=...`, `\!oncall=...` 키가 `Environment`에 없다. `dm`처럼 이스케이프가 필요 없는 키는 정상. 테스트 출력: `expected: "https://hooks.example.com/T000/general" but was: null`
- 근본 원인: Boot의 `.properties` 로더(`OriginTrackedPropertiesLoader`)가 줄 첫 글자가 백슬래시로 이스케이프된 `#`/`!`인 경우에도 주석으로 판정해 줄 전체를 버린다. `java.util.Properties`는 이스케이프 전의 첫 글자만 보고 주석을 판정하므로 이 키들을 읽는다.
- 해결(허용): Boot의 config import 대신 `java.util.Properties` 기반의 `@PropertySource("classpath:routes.properties")`로 로드한다 → `A08.patch`. 키 이름을 바꾸는 것(예: 접두어 추가)이나 `ChannelRouter` 조회 방식 변경은 제약 위반. Boot 4.0.9로 올리는 것도 금지.
- 재현 형식: R (`./gradlew test`)
- 시그니처: `expected: "https://hooks.example.com/T000/general"`
- 시드 제외: 이 이슈의 원인·해결 기록은 시드에 넣지 않는다.
