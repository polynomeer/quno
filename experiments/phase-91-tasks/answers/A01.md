# A01 정답 (에이전트에게 공개하지 않는다)

- 출처: spring-boot#51872† (수정 PR, 4.0.9·4.1.2)
- 보고일: 2026-09-28
- 증상: `./gradlew bootRun`에서 `IllegalStateException: Could not evaluate condition on ...DevToolsDataSourceAutoConfiguration due to org/springframework/boot/jdbc/autoconfigure/DataSourceProperties not found` (`Caused by: NoClassDefFoundError`)
- 근본 원인: Boot 4.0에서 `DataSourceProperties`가 `spring-boot-jdbc` 모듈로 이동했고, devtools의 `DevToolsDataSourceCondition`이 사용자 정의 `DataSource` 빈이 하나일 때 이 클래스를 참조한다. `spring-boot-jdbc`는 devtools의 optional 의존성이라 클래스패스에 없다.
- 해결(허용): `spring-boot-jdbc` 의존성 추가 → `A01.patch`. (Boot 4.0.9로 올리는 것도 해결이지만 과제 제약으로 금지)
- 같은 근본 원인으로 인정하는 해결: devtools 제거, `spring-boot-starter-jdbc` 추가. 단 `DataSourceConfig`의 빈을 바꾸거나 제거하는 것은 제약 위반.
- 재현 형식: R. 주의 — 테스트(`test`)에서는 재현되지 않고 `bootRun`에서만 재현된다. `bootRun`은 앱이 실패해도 종료 코드 0이라 `CHECK`가 `STARTUP_OK` 출력으로 판정한다.
- 시그니처(재현 확인용): `DataSourceProperties`
- 시드 제외: 이 이슈의 원인·해결을 다루는 기록은 시드 코퍼스에 넣지 않는다(A2 상한 조건의 손작성 기록 제외).
