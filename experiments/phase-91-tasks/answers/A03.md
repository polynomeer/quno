# A03 정답 (에이전트에게 공개하지 않는다)

- 출처: spring-framework#37309 (수정 7.0.10)
- 보고일: 2026-09-20 (Framework 7.0.9, Boot 4.0.8에서 확인됨)
- 증상: `expectation "expectNext(two)" failed (expected: onNext(two); actual: onComplete())` — 저장은 모두 일어나는데 방출은 첫 요소뿐
- 근본 원인: `@CacheEvict`가 `Flux`를 반환하는 메서드에서 반환 퍼블리셔를 첫 요소로 자른다(캐시 인터셉터의 리액티브 처리 버그).
- 해결(허용): `@CacheEvict`를 쓰지 않고 `CacheManager`로 파이프라인 안에서 직접 비운다 → `A03.patch`. 반환형을 `Mono<List<String>>`로 바꾸는 것도 우회가 되지만 호출 계약이 바뀌므로 비권장. Framework 7.0.10으로 올리는 것은 과제 제약으로 금지.
- 재현 형식: R (`./gradlew test`)
- 시그니처: `expected: onNext(two); actual: onComplete()`
- 시드 제외: 이 이슈의 원인·해결 기록은 시드에 넣지 않는다.
