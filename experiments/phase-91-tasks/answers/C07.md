# C07 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `NoUniqueBeanDefinitionException: No qualifying bean of type 'task.PaymentGateway' available: expected single matching bean but found 2: bankTransferGateway,cardPaymentGateway` (`UnsatisfiedDependencyException`으로 감싸임)
- 근본 원인: `PaymentGateway` 구현이 빈으로 둘이고, `CheckoutService`가 타입으로 주입하는데 파라미터 이름(`gateway`)이 어느 빈 이름과도 일치하지 않아 후보를 좁힐 수 없다.
- 해결(허용): `CardPaymentGateway`에 `@Primary` → `C07.patch`. 또는 주입 지점에 `@Qualifier("cardPaymentGateway")`, 파라미터 이름을 빈 이름과 맞추기. 구현 하나를 빈에서 제거하는 것은 과제 제약상 불가.
- 문서: [Spring Framework: @Primary로 주입 후보 좁히기](https://docs.spring.io/spring-framework/reference/core/beans/annotation-config/autowired-primary.html) (curl -sI -L 200 확인)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `NoUniqueBeanDefinitionException`
- 시드 제외 여부: 해당 없음(통제군).
