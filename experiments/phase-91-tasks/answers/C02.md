# C02 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `BeanDefinitionParsingException: Configuration problem: @Configuration class 'PaymentConfig' may not be final. Remove the final modifier to continue.`
- 근본 원인: Kotlin 클래스는 기본 final이다. `@Configuration`(proxyBeanMethods 기본값 true)은 CGLIB 서브클래스 프록시가 필요한데 `kotlin("plugin.spring")`(all-open)이 적용돼 있지 않아 클래스가 final이다. (`Application`은 `proxyBeanMethods = false`라 문제가 없고, `PaymentConfig`에서 드러난다.)
- 해결(허용): `kotlin("plugin.spring")` 추가 → `C02.patch`. 또는 `PaymentConfig`를 `open`으로 선언, 또는 `@Configuration(proxyBeanMethods = false)`.
- 문서: [Kotlin all-open 플러그인](https://kotlinlang.org/docs/all-open-plugin.html) (후보 목록에서 확인된 링크)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `@Configuration class 'PaymentConfig' may not be final`
- 시드 제외 여부: 해당 없음(통제군).
