# C04 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `java.lang.IllegalArgumentException: Unsupported class file major version 65` (`jacocoTestReport` 태스크: `Error while creating report`). 테스트 단계 stderr에도 같은 문구의 계측 실패가 찍히지만 테스트는 통과한다.
- 근본 원인: JDK 21(클래스 파일 메이저 버전 65)로 컴파일한 클래스를 JaCoCo 0.8.7(ASM이 Java 17까지만 지원)이 읽지 못한다. JDK/도구 버전 불일치.
- 구현 메모: "Gradle 래퍼 버전을 낮추는" 방식은 공유 래퍼(_common/wrapper)를 과제별로 바꿀 수 없어 쓰지 않았다. 대신 JDK 21 툴체인에서 결정적으로 같은 에러를 내는 `jacoco { toolVersion = "0.8.7" }`로 구성했다.
- 해결(허용): `toolVersion`을 JDK 21을 지원하는 버전(0.8.11 이상, 패치는 0.8.13)으로 올림 → `C04.patch`. 또는 `toolVersion` 줄 제거(Gradle 기본값 사용). 툴체인/JDK 낮추기·JaCoCo 제거·리포트 끄기는 과제 제약상 불가.
- 문서: [Gradle 호환성 표](https://docs.gradle.org/current/userguide/compatibility.html), [Gradle JaCoCo 플러그인](https://docs.gradle.org/current/userguide/jacoco_plugin.html) (둘 다 curl -sI -L 200 확인)
- 재현 형식: R (`./gradlew build`)
- 시그니처: `Unsupported class file major version 65`
- 시드 제외 여부: 해당 없음(통제군).
