# A02 정답 (에이전트에게 공개하지 않는다)

- 출처: spring-boot#52249† (수정 PR, 4.0.9)
- 보고일: 2026-10-15
- 증상: 서명이 유효한 JWT가 401. `WWW-Authenticate`에 `error_description="The iss claim is not valid"`
- 근본 원인: `jwk-set-uri` 디코더가 `issuer-uri`가 null이 아니면 `JwtIssuerValidator`를 붙인다. `issuer-uri=${ISSUER_URI:}`가 빈 문자열로 해석되면 `iss`가 정확히 `""`인 토큰만 허용된다.
- 해결(허용): `issuer-uri`가 비어 있을 때 프로퍼티를 설정하지 않는다(줄 제거, 프로필 분리 등). → `A02.patch`. Boot 4.0.9로 올리는 것은 과제 제약으로 금지.
- 같은 근본 원인으로 인정하는 해결: 직접 `JwtDecoder`를 구성해 빈 issuer를 걸러내기. 단 issuer가 설정된 경우의 검증은 유지해야 한다.
- 재현 형식: R (`./gradlew test`)
- 시그니처: `The iss claim is not valid`
- 시드 제외: 이 이슈의 원인·해결 기록은 시드에 넣지 않는다.
