# C05 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `Web server failed to start. Port 8080 was already in use.` (`org.springframework.boot.web.server.PortInUseException: Port 8080 is already in use`, 원인 `java.net.BindException: Address already in use`)
- 근본 원인: `application.properties`가 `server.port=8080`으로 고정돼 있는데, `CHECK`가 8080을 점유한 다른 프로세스(개발 머신의 다른 로컬 서비스를 흉내)를 띄운다.
- 해결(허용): 앱 포트를 다른 값으로 변경(`server.port=18080` → `C05.patch`). 또는 `server.port=0`(랜덤 포트), 환경변수/시스템 프로퍼티로 재정의. 점유 프로세스를 죽이는 것, 테스트·CHECK 수정은 과제 제약상 불가.
- 주의: 이 개발 머신에서는 Docker가 실제로 8080을 점유하고 있다. CHECK는 8080 점유에 실패해도(이미 다른 프로세스가 쓰는 중이므로) 그대로 진행하고, 이때도 같은 에러가 난다. 점유 리스너의 동작은 포트를 18080으로 바꾼 사본에서 확인했다(리스너가 PortInUseException을 일으키고 CHECK 종료 시 정리됨).
- 문서: [Spring Boot How-to: Embedded Web Servers](https://docs.spring.io/spring-boot/how-to/webserver.html) (curl -sI -L 200 확인)
- 재현 형식: R (`./CHECK`가 점유 리스너를 띄운 뒤 `./gradlew test`)
- 시그니처: `Web server failed to start. Port 8080 was already in use.`
- 시드 제외 여부: 해당 없음(통제군).
