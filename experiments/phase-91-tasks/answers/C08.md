# C08 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `org.hibernate.LazyInitializationException: Cannot lazily initialize collection of role 'task.Order.items' with key '1' (no session)`. (Hibernate 5/6의 `failed to lazily initialize a collection ... could not initialize proxy - no Session`과 같은 에러의 Hibernate 7 문구.)
- 근본 원인: `findDetail`이 트랜잭션 없이 엔티티를 돌려주고(`findById`의 트랜잭션은 호출 안에서 끝남), 호출자가 지연 로딩 컬렉션 `items`를 건드릴 때는 영속성 컨텍스트가 이미 닫혀 있다. `open-in-view=false`라 요청 범위로 세션이 연장되지도 않는다.
- 해결(허용): 필요한 시점에 함께 읽기 — `@EntityGraph(attributePaths = ["items"])`/fetch join 조회 → `C08.patch`. 또는 `findDetail`에 `@Transactional(readOnly = true)` + `Hibernate.initialize(order.items)`. 금지(과제 제약): `FetchType.EAGER`로 변경, `open-in-view=true`, `enable_lazy_load_no_trans`, 반환 타입 변경.
- 문서: 링크 미확인
- 재현 형식: R (`./gradlew test`)
- 시그니처: `LazyInitializationException: Cannot lazily initialize collection of role 'task.Order.items'`
- 시드 제외 여부: 해당 없음(통제군).
