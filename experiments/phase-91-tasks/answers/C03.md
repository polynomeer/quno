# C03 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `JpaSystemException: No default constructor for entity 'task.Payment'` (원인 `org.hibernate.InstantiationException`). 기동 시 `HHH000182: No default (no-argument) constructor for class [task.Payment]` 경고가 먼저 나온다.
- 근본 원인: Hibernate는 엔티티를 인자 없는 생성자로 만든다. `Payment`는 주 생성자에 인자가 필수라 기본 생성자가 없고, `kotlin("plugin.jpa")`(no-arg)가 적용돼 있지 않다.
- 해결(허용): `kotlin("plugin.jpa")` 추가 → `C03.patch`. 또는 모든 생성자 파라미터에 기본값을 줘 합성 기본 생성자를 만들기, 보조 `protected constructor()` 추가. 단 `val` 불변성은 유지.
- 문서: [Kotlin no-arg 플러그인](https://kotlinlang.org/docs/no-arg-plugin.html) (후보 목록에서 확인된 링크)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `No default constructor for entity 'task.Payment'`
- 시드 제외 여부: 해당 없음(통제군).
