# C01 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `BeanCurrentlyInCreationException` (`UnsatisfiedDependencyException`로 감싸여 컨텍스트 로딩 실패)
- 근본 원인: `OrderService` ↔ `InventoryService`가 생성자 주입으로 서로를 요구한다. Spring Boot 2.6부터 순환 참조는 기본 금지다.
- 해결(허용): 순환을 끊는 설계 변경(공통 의존을 `OrderLedger`로 추출 → `C01.patch`), 한쪽 생성자 파라미터에 `@Lazy`. `spring.main.allow-circular-references=true`는 생성자 순환에는 효과가 없고, 설정으로 금지를 푸는 방식은 권장하지 않는다.
- 문서: [Spring Boot 2.6 릴리스 노트](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-2.6-Release-Notes) (후보 목록에서 확인된 링크)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `BeanCurrentlyInCreationException`
- 시드 제외 여부: 해당 없음(통제군은 잘 알려진 에러라 시드 대상이 아님).
