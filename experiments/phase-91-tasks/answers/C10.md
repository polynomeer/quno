# C10 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `kotlin.UninitializedPropertyAccessException: lateinit property discountPolicy has not been initialized`
- 근본 원인: `lateinit var discountPolicy`는 누군가 채워 줘야 하는데 `@Autowired`가 없어 Spring이 주입하지 않는다(컨텍스트는 정상 기동). `quote()`가 처음 접근할 때 예외.
- 해결(허용): 생성자 주입으로 변경 → `C10.patch`(권장). 또는 필드에 `@Autowired`. `DiscountPolicy`를 서비스 안에서 직접 생성하는 방식은 과제 제약(구조 유지)상 불가.
- 문서: [Kotlin: 프로퍼티와 late-initialized 프로퍼티](https://kotlinlang.org/docs/properties.html) (curl -sI -L 200 확인)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `lateinit property discountPolicy has not been initialized`
- 시드 제외 여부: 해당 없음(통제군).
