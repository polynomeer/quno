# C06 정답 (통제군 — 에이전트에게 공개하지 않는다)

- 분류: C층 통제군. 흔하고 문서화된 에러 — 코딩 에이전트가 혼자 풀 수 있어야 하는 과제.
- 에러: `Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured.` (`DataSourceBeanCreationException`)
- 근본 원인: `spring-boot-starter-jdbc`와 PostgreSQL 드라이버만 있고 `spring.datasource.url`이 없으며, 클래스패스에 임베디드 DB(H2 등)도 없어 DataSource를 구성할 수 없다.
- 해결(허용): 테스트용 임베디드 DB 추가(`testRuntimeOnly("com.h2database:h2")`) → `C06.patch`. 또는 `src/test/resources`에 H2 URL을 쓰는 설정 + H2 의존성. 실행 중인 PostgreSQL이 필요한 해결은 과제 제약상 불가.
- 문서: [Spring Boot How-to: Data Access](https://docs.spring.io/spring-boot/how-to/data-access.html) (curl -sI -L 200 확인)
- 재현 형식: R (`./gradlew test`)
- 시그니처: `Failed to configure a DataSource: 'url' attribute is not specified and no embedded datasource could be configured.`
- 시드 제외 여부: 해당 없음(통제군).
